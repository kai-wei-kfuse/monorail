## 没做真窗口实测的原因

真窗口项要求隔离安装（关闭开机自启、隔离快捷键、记录并清理 Windows Run 项，不碰日常版的数据和安装）。本次只做到 debug 构建，没有建隔离身份运行，所以执行方案 §4.4 列出的 D2–D8 真窗口项和 v0.2.5 兼容矩阵都没有做。发版前需要补上。
