# 0.2.4：背包任务卡直接点击开始计时与卡片交互优化

日期：2026-10-31。完成本地代码实现与自动化测试验证，尚未发布、安装或替换日常运行程序。

最终状态：用户于 2026-10-31 确认已完成手测；整体代码审核、最终 424 项测试及正式配置构建结果见 [发版准备记录](release-0.2.4/summary.md)。下方测试数量是各轮开发时的历史记录，以最终记录为准。

## 改动与范围

- `src/pages/backpack/TaskPool.tsx`、`src/pages/backpack/taskpool.css`：
  - 单事项任务（`isSingle(task) === true`）：标题 `<h4 className="qc-title">` 下方 Meta 行改为左右两端对齐容器 `.qc-single-row`，左侧保留 `<Meta item={task.items[0]} />`，右侧放置 `<Button size="sm">{item.running ? '进行中' : '开始'}</Button>`。
  - 多事项任务（`!isSingle(task)`）：每个事项 `<li>` 改为 `.qc-item-row`，左侧保留 `.qc-item` 编辑按钮，右侧同级放置 `<Button size="sm">{item.running ? '进行中' : '开始'}</Button>`（无 `<button>` 嵌套，点击开始不触发编辑弹窗）。
  - 事项正在计时（`item.running === true`）时文案显示为「进行中」并禁用按钮。
  - 底部操作收口至分类选择器（`ProjectPicker`）右侧同一行（`.qc-proj-r`）的双向下箭头（`Tri2`）下拉菜单 `.qc-menu`，去掉左侧的「计时记到」文字（保留 `LOG TO`），展开后依次提供「拆分任务」（单事项）或「添加任务」（多事项）、「冷藏」、「放弃」三项操作。
  - **按钮内双箭头居中修复**：原 `.sbtn.sm`（位于 `controls.css`）对 `.qc-menu-btn` 具有更高优先级，其 `padding: 0 10px` 覆盖了 `.qc-menu-btn { padding: 0 }`，且 `Tri2` 的 `viewBox="0 0 10 14"` 图形高为 `0..12.6`（底部留白 `1.4`），导致图标向右偏且偏上。现通过 `.qc-menu .sbtn.sm.qc-menu-btn { width: 28px; height: 28px; padding: 0; }` 与 `svg { width: 10px; height: 13px; transform: translateY(0.5px); }` 使其水平垂直严格居中。
  - 菜单展开时通过 `useLayoutEffect` 与 `shouldOpenMenuUp` 测量菜单实际高度及可滚动裁切祖先（`.s-panel`）的可视边界，并在面板滚动与窗口缩放时动态重算向上/向下弹出方向，支持点击外部或按 `Escape` 关闭。
  - **右下角折角边线对齐修复**：原 `.qc` 直接设 `border: 1px solid; border-bottom-width: 3px` 与 `clip-path`，而 `.qc::after` 定位在 `padding-box` 内，导致折角斜线相对外边界向左偏移 1px、向上偏移 3px，且 `.qc` 的 `clip-path` 会裁切伸出卡片的下拉菜单。现将卡片背景、边框与 `clip-path` 统一收口到外边界对齐的 `.qc::before`（`inset: 0`），`.qc::after` 同样对齐外边界右下角 `14px × 14px` 并精确连接右侧 1px 边框切口 `(13px..14px, 0..2px)` 与底部 3px 边框切口 `(0..2px, 11px..14px)`，同时解除对下拉菜单的裁切。
- `src/pages/backpack/BackpackPage.tsx`、`src/app/BackpackScreen.tsx`：
  - `PoolActions` 新增 `startItem(itemId: string)`，`BackpackActions` 新增 `startCard(cardId: string, at: string)`。
  - `BackpackScreen` 组装层直接调用 `homeService.startCard(ctx, cardId, at)`，点击后停留在背包页，错误统一经 `report` 汇报。
- `src/app/dev/BackpackPreview.tsx`、`src/app/dev/TaskPoolPreview.tsx`：同步补齐预览动作。
- `src/shared/duration.ts`、`src/widgets/cardProgress.ts`、`src/pages/home/TimerBar.tsx`、`src/app/MiniApp.tsx`、`src/pages/backpack/TaskPool.tsx`、`src/app/dev/TimerPreview.tsx`：
  - **计时读数进位显示（消除几百分钟与 `00:` 前缀，唯一规则源收口）**：以 `shared/duration.ts` 的 `formatReadout(ms, 'mmss')` 为唯一规则源，不到 1 小时显示 `MM:SS`（省略 `00:` 前缀），满 1 小时及超过 24 小时进位显示 `HH:MM:SS`（如 `01:47:17`、`25:04:05`）；`formatReadout(ms, 'hms')` 保持 3 段 `HH:MM:SS` 输出，维护两种 `kind` 下 `parseReadout(formatReadout(ms, kind), kind, 0) === ms` 的往返不变量。`formatMinutes`、`TimerBar`、`MiniApp` 超时提示、`TaskPool` 的 `clock` 及 `TimerPreview` 统一复用 `formatReadout`。
- `src/pages/list/EntryRow.tsx`、`src/pages/list/ListPage.tsx`、`src/pages/list/list.css`、`src/services/tracking/timeEditService.ts`、`src/app/dev/ListPreview.tsx`：
  - **列表页分类与标签选择器无框简约化及单行防折行**：`EntryRow` 中的 `ProjectPicker` 与 `TagPicker` 改为 `flat` 模式（与首页卡片头部「记到」行一致，去掉外框、底色和黑色下拉箭头块，未加标签时显示 `＋ 标签`），合并行的 `.lv-cat` 与 `.lv-tags .chip` 同步对齐无框样式；同时缩短 `.lv-desc`（`1 1 120px; min-width: 80px`）、`.combo.flat` / `.lv-cat`（`min-width: 56px`）、`.tagpick.flat` / `.lv-tags`（`0 1 136px; min-width: 52px`）、`.lv-tin`（`48px`）与 `.lv-dur`（`82px`）的占位宽度，并将 `.lv-row` 设为 `flex-wrap: nowrap`，避免右侧 `⋯` 菜单按钮被挤到下一行。
  - **列表页时长显示与编辑语义对齐**：`duration(ms)` 复用 `formatReadout(ms, 'mmss')`（不到 1 小时显示 `MM:SS` 省略 `00:`，满 1 小时显示 `HH:MM:SS`），同时 `setDurationInTx` 改用 `parseReadout(text, 'mmss', current)` 解析，使 `45:01`（45 分 1 秒）、`01:15:01`（1 小时 15 分 1 秒）、`90`、`1h 30m` 与显示值完全往返一致，且不改变全局 `parseDuration` 契约。
- `src/pages/home/FusedCard.tsx`、`src/pages/home/TaskCard.tsx`、`src/pages/home/home.css`：
  - **融合布局自由记录与任务卡标题样式统一（保持 `useEntry` 架构不变）**：`FusedCard` 保持 `.f-input` 与 `useEntry` 的焦点组及 `parseEntryText`（`#标签` / 项目快捷语法）提交架构不变，将 `.f-title` 字号统一为 `var(--ts, 62px)`（由 `titleScale` 计算传入），并在已有内容且未展开下拉建议框时添加 `.compact`（`width: auto; field-sizing: content`），使 L 形角标 `.tbox` 像任务卡一样紧凑包裹文字宽度，消除右侧大片空白；同时 `TaskCard` 的 `useLayoutEffect` 在 `!h || !t`（进入 `InlineInput` 编辑卸载 `h1`）时直接返回保留已测量的 `ts`，避免长标题编辑时字号跳回 62px。
- `src/pages/backpack/TaskPool.test.ts`、`src/shared/duration.test.ts`、`src/widgets/cardProgress.test.ts`、`src/pages/list/listGroups.test.ts`、`src/pages/home/fused.test.ts`、`src/services/homeService.test.ts`、`src/app/actions.test.ts`：
