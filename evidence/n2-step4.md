# N2④：v2 运行链与卡系统接入

2026-10-28。

- 启动先封住原生快速保存、恢复 journal、迁移、读取 v2 schema 并扫描校验条目，完成初始化后开放保存。迁移失败保留明确错误和关闭状态，避免旧格式继续被写入。
- 运行时移除 seq、max_seq、stopped_day、旧 timerService、effective 与 v1Codec；旧解析和覆盖语义仅保留在 data/migrations/v1。
- commit 使用条目索引，单事务写入变化的活动日及实体文件，提交后发布；更改日边界也重算当前条目的文件指针。
- 卡开始/完成/缩小/再抽/PASS/编辑、背包冷藏放弃、回顾与降级改走 tracking/api；首页与离线调度由 homeService 编排并对齐。
- 任务分主线/支线，以状态表示冷藏/完成；单项支线、容量检查、首次拆分候选、支线自动完成规则集中在 task/pool。记录条收集不因支线容量满而拒收。
- 卡的计时项目取卡 → 任务默认 → 未分类；暂停后恢复使用当前卡模板。补录并存，跨日不切片。
- 读数确认检查目标与完整预览；固定点击时刻；不足一分钟也提示；同引用并行历史的累计值修改有独立回归。旧补记弹窗不能携带覆盖确认凭据时明确拒绝并回滚，N3 计时条接线后替代该入口。
- 启动/新待办/离线不自动出卡。主页增加最小空状态抽卡入口以保持本阶段可操作；完整计时条及融合布局由 N3 接线。
