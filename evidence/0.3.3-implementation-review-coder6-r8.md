## 关闭的已报缺陷

- generation 必须为正安全整数，check/restore 同时核对 requestId 与 generation；缺失/NaN/Infinity/负数/小数/超安全整数均不推进或解锁。旧 check、先到 restore、同代错 ID、同 ID 错代均有独立回归。
- Rust ACK 从真实 WebviewWindow 取 caller，缺/空/错轮/集合外 caller 不推进；重复 clean 不覆盖首份 dirty。并发 begin 不替换原轮，取消必须匹配本轮 ticket。未全齐或 dirty 的检查不授权退出，clean 同 ID 才能授权，取消撤销授权。
- dirty 检查显式携本次 MaintenanceCheckError.requestId，准入拒绝没有 ticket；MainApp/Settings 调用生产编排，安装服务 prepare 失败不取消他人轮次。全局 active 猜属已移除，正常错误只取消自己取得的 ticket。
