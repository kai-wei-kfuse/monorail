# 0.2.5 P2e：临时活动期间禁用底部操作

日期：2026-11-01。用户截图明确要求底部按钮在临时活动中灰色不可按，悬停提示「从临时活动回来后可用」。已完成。

## 行为与实现

- 融合布局自由记录/任务卡、分开布局计时条/自由记录卡/任务卡，以及空白卡的底部操作组，使用共享 `ActivityActions` 原生 disabled fieldset。只根据已提交 `view.away` 禁用，不新增业务状态或服务权限判断。
- 暂停、停止、＋、抽卡及卡自身传入的按钮统一受组约束。pending 与 away 并存时，底部放弃等也禁用。原位置与尺寸保持，CSS grayscale 加既有 disabled opacity 呈现灰色。
- 禁用按钮不接收鼠标事件，外层组承接悬停并提供原生 title 提示，避免旧按钮自身 title 遮住禁用原因。原生 fieldset 同时阻止键盘聚焦/激活；不是仅靠 CSS 阻挡点击。
- 抽屉「回来」继续可用。回来后解除组禁用，各按钮自己的 canDraw/busy 等禁用条件仍保留。卡头、手动补录、快捷键及服务层行为不在本次改动范围。

ADR 0006 v1.3 已明确取代旧版允许底部操作的约定；计划、上级 UI/产品规格及发版说明同步。旧阶段审核保留其当时的历史结论，以本记录作为最新按钮可用性证据。

## 文件

`src/pages/home/ActivityActions.tsx`、`activityActions.css` 统一原生禁用与提示；`TaskCard.tsx`、`TimerBar.tsx` 承载操作组；`FusedCard.tsx`、`FreeCard.tsx`、`HomePage.tsx` 传递临时活动状态。更新 `fused.test.ts`、`awayDrawer.test.ts` 及原 `away-review-repro.mjs`，将旧“按钮可用”要求改为“保留布局但禁用”。
