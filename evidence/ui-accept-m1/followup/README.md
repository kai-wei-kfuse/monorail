## 结论（每条一行）

1. 期限输入：`ui/controls/DateTimeInput` 改成自绘控件，记录条和卡片编辑器都在用。不再使用原生 datetime-local。
   - 日期、时间两格手写。日期可以写「明天」「10/28」「1028」；时间可以写「18」「1830」「18:30」。
   - 只写日期时，时间算 23:59；只写时间时，算今天，如果已经过了就算明天；没写年份且日期已经过去时，算明年。
   - 失焦或按 Enter 时提交，写不对时边框变红。方向键：日期格 ±1 天，时间格 ±15 分钟。
   - 空着时显示「今天/明天」快捷按钮，有值以后换成清除按钮，这样记录条 760 宽也能放在一行（01/02/03）。
   - 解析规则有单元测试，在 controls.test.ts。
2. 通知位置：挪到右上角，在标题栏下方 12px（`top: 52px`），不再挡住大号读数（04）。
3. 通知文案：开发用语都去掉了（MainApp.tsx）。
   - 「添加快捷活动」「添加休息项」这两个按钮在设置页接上之前直接不显示，对应的通知也删了。QuickActs 的 `onAdd`、RestCard/HomePage 的 `onAddRest` 改成可选参数（08）。
   - 还要点得动的三处，改成了面向用户的话：引导卡写「先写一条待办 / 项目功能还在做……」；接受支线提示写「支线项目还不能新建 / 可以先在记录条里把它记成一条想法」；回顾卡写「每周回顾还不能用 / 回顾页还在做，做好后从这里进入」。
4. 「今天不再出卡」改成两步确认，新增 `pages/home/ConfirmLink.tsx`。第一次点变成「确认今天不再出卡？」；3 秒内再点才调用 stopToday，`at` 取确认那一下的时间；超时或者失焦就恢复原样。service 没有改（05/06）。
5. 引导卡「设定主线」的按钮图标改成 →（`Icon` 新增 `arrow`）（07）。

## 遗留，供决定

- 通知挪到右上以后，第一条会盖住卡片右上角的小字（「还没有主线」「今天不再出卡」「回来 · 厕所」），要等通知关掉或者自动消失才能看到（04）。说明性通知 6 秒后会自己消失；需要回答的提示（例如「已经持续 4 小时」）会一直留着，直到用户回应或关掉。
- 卡片编辑器（widgets/CardEditor.tsx）在期限旁边还有自己的「清除」按钮，和新控件里的 × 重复了。widgets 不在这次的改动范围里，没有动，建议删掉那个按钮。
