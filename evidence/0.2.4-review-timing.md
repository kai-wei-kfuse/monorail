# 0.2.4：回顾不再自动计时

日期：2026-10-31。完成本地开发与验证，尚未发布、安装或替换日常运行程序。

## 改动与范围

- `src/services/reviewService.ts`：移除进入回顾时释放卡、清空休息、开始回顾计时，以及完成回顾时切回待机的逻辑；回顾服务不再直接调用 tracking API。
- `src/app/ReviewScreen.tsx`：挂载仍恢复回顾进度，注释同步为不控制计时。
- `src/domain/review/flow.ts`：标明 `timer_entry_id` 仅为历史兼容，不改 schemaVersion 2 或旧迁移。
- `src/services/reviewService.test.ts`、`reviewTiming.test.ts`：更新旧计时断言，增加计时与状态保持的流程测试。
- npm/Cargo 及两份锁文件同步至 0.2.4；决定、当前计划及用户修改说明分别见 ADR 0004、`docs/stages/0.2.4.md`、`docs/releases/0.2.4.md`。
- 仓库上级的 `架构设计.md` §2.1、§2.4 及 `像素记录系统 设计文档 v0.3.md` A8、A9 同步当前规则并记录修订。这两份文档位于 app Git 仓库之外。

## 兼容与交接

历史回顾计时不删除、不自动截断；用户仍可通过既有计时入口切换。主线复盘中明确冷藏或放弃任务，仍会按背包服务规则结束相关任务计时。
