- StopButton 保留原有停止回调、aria-label 与 pending 草稿保护标记，仅增加 stop 样式。图标内部方块从 9×9 调至 10×10，SVG 使用 22×22，颜色来自已有 var(--red)，悬停 CSS 为红底白字。作者 DOM 报告实测常态颜色 rgb(196,43,28)、SVG 22×22，截图显示红色停止方块。
