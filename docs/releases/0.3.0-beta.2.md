# 单轨 0.3.0-beta.2

这是 Beta 测试版。

- 设置新增「AI 与自动化」页，可在应用内了解 MCP 与 CLI 的使用方式、已有能力及本机访问范围。
- 根据当前安装位置生成 MCP 配置与 6 条常用 PowerShell CLI 命令，支持逐项复制，并显示复制成功或失败的结果。
- 补充 Node.js 24 运行要求、首次初始化与后台按需启动说明，以及入口路径缺失、待确认状态和操作结果未知等问题的排查指引。

保留 beta.1 的共享应用接口、MCP/CLI 和 Beta 渠道功能。使用 MCP 或 CLI 前需在本机安装 Node.js 24 或更高版本；操作会实际影响本地记录和计时状态。
