# 单轨 0.2.4

- 背包里的任务卡现在可以直接点击「开始」计时，无需随机抽卡：分成多个小任务的，每个小任务右侧都有「开始」按钮；没有拆分小任务的，标题下方直接提供「开始」按钮；正在计时的事项会显示「进行中」。
- 任务卡底部的「拆分任务 / 添加任务」「冷藏」「放弃」整合进分类选择器右侧的下拉菜单，去掉了左侧「计时记到」文字，并修复了任务卡右下角折角边线不对齐的问题。
- 计时读数不再累加显示成几百分钟：不到 1 小时显示 `分:秒`（不显示 `00:`），满 1 小时起进位显示 `时:分:秒`。
- 列表页的分类与标签选择器改为无框简约样式，缩短列间空白，让右侧操作按钮保持同行；编辑时长时，分秒与时分秒写法和显示一致。
- 首页融合布局下，自由记录进行中时的标题字号与角标样式与任务卡统一。
- 打开、重新进入或完成每周回顾时，不再自动切换计时。原来正在记录的活动继续计时，暂停、休息及待确认状态也会保留。
- 回顾步骤仍会自动保存，下次打开可以接着做。

不改变数据格式。历史回顾计时记录保留。
