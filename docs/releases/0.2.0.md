# 单轨 0.2.0

这一版把计时和卡合到一起：首页就是一个计时入口，卡是计时的一件事。第一次打开会升级数据，升级前自动备份。

- 数据升级：第一次启动时把数据转成新格式，原来的文件先完整复制到数据目录里的 `backup/v1-<时间>/`。升级只做一次；升级期间快速记录条会提示稍后再存，草稿保留。
- 首页：上面是计时条，点输入框就开始计时，写下在做什么或者抽一张卡。确认之前不写盘，确认以后这段时间算在那件事上。「＋」开始想下一件事，当前这条照常计。
- 读数点一下就能改：`45` 是 45 分钟，`1:30`、`1h 30m` 也认，`+10` / `-5` 加减分钟。会盖掉别的记录时先提示，点确定才改。
- 卡头「记到」那一行，点一下就能改这张卡记到哪个项目、加标签。
- 收藏：计时条下面一行，数字键 1–9 启动，可以拖动排序。正在计的那条旁边点图钉就能收藏。
- 设置 → 外观 → 首页布局：「融合」把计时条并进大卡，标题区就是输入框。
- 新增日历和列表：拖动新建、移动、改起止，同一段时间的几件事并排显示；列表按天合并同名记录。
- 背包改成任务池：主线任务、支线任务，每个任务下面若干项；待办就是只有一项的支线任务。想法可以转成任务。
- 小窗是独立窗口，可以和主窗口同时开着，能暂停、继续、完成、改名和改时间。
- 「类别」改叫「项目」，可以自己加，每个项目一个颜色。收藏和快捷活动在设置 → 预设与休息池里编辑。

升级以后不能直接装回 0.1.4 使用同一个数据目录。需要回退时，照 `docs/releases/0.2.0-回退.md` 操作。

私有开发版需安装 GitHub CLI，并通过 gh auth login 登录可读取此仓库的账号。
