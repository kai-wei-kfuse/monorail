# 单轨 0.3.0

0.3.0 正式版，包含 0.3.0 三个 Beta 版的全部内容，另外给小窗和想法池加了新功能。从 0.2.5 更新过来，原有数据照常使用。

## 小窗

- 小窗口和 mini 窗口都能选分类。小窗口在「记到」后面选，写新事件时也能先选好再回车；mini 窗口点名称右边的分类块切换。名称里写了 `@项目` 时，以名称里的为准。
- 在小窗里写新事件时，会和主窗口一样列出收藏、待做的卡和最近的记录，点一项就开始。
- 列表在下面放不下时会翻到上面展开，小窗本身不动；收起后回到原来的大小和位置。
- mini 窗口去掉了关闭「×」，读数字号改小，名称能多显示几个字。关 mini 窗口用主窗口底栏的「关闭小窗口」、按 M 或托盘。
- 按 F5 刷新主窗口或更换数据目录以后，小窗不再误报「主窗口未响应」。刷新前在小窗里没改完的内容会清掉，不会被提交。
- 小窗右侧黑色计时区的右下角不再漏白，左上斜角的顶边线也连上了。

## 想法池

- 每条想法多了〔完成〕按钮：已经做到、不用再转成任务的想法，点一下就收进「已完成」，不占想法池上限，也不会进冷库。
- 想法池上方可以切换「想法池 / 已完成」。「已完成」里写着完成时间和是谁标的（手动、MCP 或 CLI），点〔撤销完成〕放回想法池。

## 回看

- 回顾页里的「回看」随时都能看，不再只在每周回顾的第一步出现。
- 可以选本周、上周、本次回顾周期、本月、近 3 个月、最近一年或自定义时间，按项目分类、标签、任务与来源、具体活动分组。
- 有分色柱状图和构成环形图，点一根柱子，下面的明细只看那一段；顶部 4 张概览卡（有效投入、主线投入、完成的事项卡、做到哪了）都和上一期对比。
- 有效投入按实际占用的时间算，同一时刻几条记录并行只算一次。待机和睡眠默认不算，可以打开开关一起看。
- 上次选的时间范围、分组和显示方式会记住。

## 操作历史

- 「列表」页右上可以切到「操作历史」，记下所有改动了数据的操作：你在主窗口、小窗、快速记录条里做的，MCP 和 CLI 调用的，以及软件按规则自己做的（标「系统」，比如切换活动日、电脑休眠后补记离线时段）。
- 每条写着时刻、来源、做了什么、改的是哪一条，点开能看改前改后；MCP / CLI 的调用还能看到调用方和原始参数。
- 可以按「全部 / 仅自动化 / 仅手动 / 仅系统」筛选和搜索；右边的 ◎ 跳到对应的那一天或页面。
- 只能查看，不能撤销。保留最近 180 天，更早的自动清理，只清理操作历史本身。

## 日历与列表

- 日历里拖动和新建的最小间隔改为 1 分钟，很短的条目也能点开。
- 日历条目弹窗里可以直接改开始时间、结束时间和时长。
- 底栏「快捷活动」里去掉了固定的「睡觉」，只显示你自己添加的快捷活动。

## AI 与自动化（MCP / CLI）

- 安装包自带本地 MCP 服务和命令行工具（CLI）。AI 客户端或脚本可以保存想法、把想法标成完成、记待办、查找事项、查看当前计时和时间统计、补记时间、开始 / 暂停 / 停止计时、插入休息再回来。
- 设置新增 09「AI 与自动化」页：按当前安装位置生成 MCP 配置和常用 CLI 命令，可以逐项复制；「最近调用」列出最近 5 次 AI 或脚本改动数据的调用。
- 使用 MCP 或 CLI 需要本机安装 Node.js 24 或更高版本；这些操作会实际改动你的记录和计时。
- **更新单轨以后请重启 AI 客户端。** 客户端还在用旧版本的 MCP 进程时，新旧两边可能对不上。

## 更新与 Beta 渠道

- 「设置 → 关于 → 软件更新」可以加入或退出 Beta 体验。默认是稳定版渠道；退出 Beta 后可以留在当前版本等下一个正式版，也可以选「安装稳定版」。
- 从 0.3.0 起，应用内安装更新前会先完整备份数据和配置并逐个校验，备份不成功就不安装。
- 也可以从 GitHub Releases 下载安装包直接覆盖安装：先退出单轨，安装向导里选「请勿卸载」，不要勾选「删除应用程序数据」。

## 已知情况

- 「最近一年」的回看在数据很多时，切换选项要稍等片刻。
- 退回 0.2.5 时数据都在，但旧版看不到操作历史，退回期间的操作回到新版后也不会补记；已完成的想法在旧版里显示成冷库里的想法。
