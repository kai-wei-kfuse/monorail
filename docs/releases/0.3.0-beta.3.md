# 单轨 0.3.0-beta.3

这是 Beta 测试版。

## 回看

- 回顾页里的「回看」随时都能看，不再只在每周回顾的第一步出现。本期回顾做完以后，回顾页直接显示回看。
- 可以选 7 种时间范围：本周、上周、本次回顾周期、本月、近 3 个月、最近一年和自定义时间。自定义时间用两个月并排的日历选起止日期。
- 可以按项目分类、标签、任务与来源、具体活动分组查看。
- 有每天（时间长时按周、按月）的分色柱状图和构成环形图；点一根柱子，下面的明细只看那一段。
- 顶部 4 张概览卡：有效投入、主线投入、完成的事项卡、做到哪了，都和上一期对比。
- 有效投入按实际占用的时间算：同一时刻几条记录并行只算一次。待机和睡眠默认不算，可以打开开关一起看。
- 明细可以展开看每一条；「完成的卡」和「做到哪了」可以切换列表和卡片两种样子。
- 上次选的时间范围、分组和显示方式会记住，下次打开照旧。

## 操作历史

- 「列表」页右上可以切到「操作历史」。改动了数据的操作都记在这里：你在主窗口、小窗、快速记录条里做的，MCP 和 CLI 调用的，以及软件按规则自己做的（标「系统」，比如每天切换活动日、电脑休眠后补记离线时段）。
- 每条写着时刻、来源、做了什么、改的是哪一条；点开能看改前改后和连带改动。MCP / CLI 的调用还能看到调用方、方法、`operation_id`（可复制）和原始参数，CLI 的会写出当时的命令。
- 可以按「全部 / 仅自动化 / 仅手动 / 仅系统」筛选，选「仅自动化」时还能按调用方筛选；可以搜索动作、内容、调用方和 `operation_id`。
- 右边的 ◎ 跳到对应的那一天或对应的页面。
- 设置 → 09「AI 与自动化」新增「最近调用」，列最近 5 次 AI 或脚本改动数据的调用，点一条跳到操作历史里的那一条。
- 只能查看，不能撤销。保留最近 180 天，更早的会自动清理；只清理操作历史，不动计时、卡片等数据。
- 只读的查询、失败或被拒绝的调用不记。设置里 1 分钟内连续改同一项会合成一条。

### 调用方

- MCP 的调用方取 AI 客户端连接时自己报的名字。
- CLI 可以加 `--agent 名字`，或者设环境变量 `MONORAIL_AGENT`，说明是谁在调用；都没有时会认几个常见 AI 工具的环境变量，认不出来记「未识别」。
- 调用方都是对方自己报的，只用来显示和筛选。
- **更换单轨版本后请重启 AI 客户端。** 客户端还在用旧版本的 MCP 进程时，新旧两边可能对不上。

## 日历与列表

- 日历里拖动和新建的最小间隔改为 1 分钟，很短的条目也能点开。
- 日历条目弹窗里可以直接改开始时间、结束时间和时长；项目和标签改成和列表一样的无边框样式。

## 小窗

- 按 F5 刷新主窗口，或者更换数据目录以后，小窗不再误报「主窗口未响应」。刷新前在小窗里没改完的内容会清掉，不会被提交。
- 小窗右侧黑色计时区的右下角不再漏白，左上斜角的顶边线也连上了。
- 在小窗里点「完成」、回到主窗口确认后，操作历史里记的来源是小窗。

## 其他

- 底栏「快捷活动」弹层里去掉了固定的「睡觉」，只显示你自己添加的快捷活动。

## 已知情况

- 「最近一年」的回看在数据很多时，切换选项要稍等片刻。
- 退回 0.2.5 以后，旧版看不到操作历史，退回期间的操作在回到新版后也不会补记。

保留 beta.2 的全部功能。使用 MCP 或 CLI 前需在本机安装 Node.js 24 或更高版本；操作会实际影响本地记录和计时状态。
