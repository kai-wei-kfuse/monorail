# 单轨 0.3.2

0.3.2 补齐了背包任务详情里的**单子项完成 / 取消完成**与**完成整张任务 / 重新打开**，在小窗口与自由计时中补上了一致的**显式〔插入事件〕**入口，把开始任务卡的**拉开大幕转场（Wipe）**接到背包与今日任务板的每个〔开始〕入口，调整了底栏左侧四个操作按钮的紧凑间距，并将 **0.3.x 全部 A–D 自动化能力（共 36 个应用方法）** 完整覆盖到 MCP 与 CLI。从 0.3.1 / 0.3.0 / 0.2.5 更新过来，原有数据照常使用（已通过与历史标签 `v0.3.1`、`v0.3.0`、`v0.2.5` 一致的 `MdRepo` 与 `taskSchema` / `cardSchema` 读写往返单测校验）。

## 任务详情：单子项完成、取消完成与完成整张任务

- **单子项完成**：在背包点开任意任务的〔详情 ›〕，每一行待做或进行中的子任务左侧方框与右侧〔完成〕按钮都可以直接完成该子项（今日任务板行保持简洁，不额外塞完成按钮）。
  - 完成普通待做子项时，不会打断当前正在计时的其他任务卡、自由计时或插入事件。
  - 完成当前正在计时（或已暂停）的任务卡时，会结束该卡计时并回到空卡区；若是时间盒卡且尚未达到今日目标时长，会先弹出确认框询问是否提前完成。
- **单子项取消完成**：任务详情下方已完成的子任务行（灰显带 `✓`），点左侧 `✓` 方框或右侧〔取消完成〕即可把这一项恢复为「待做」，原有的已计时间、项目、标签和进度笔记完整保留，不会自动开始计时。
- **完成整张任务与已完成列表**：
  - 任务详情底部新增〔✓ 完成整张任务〕，确认后将整张主线或支线任务标为「已完成」，剩下还没做的子任务一并完成，同时立即腾出对应的主线/支线背包格。
  - 背包「任务」页顶部新增〔进行中 | 已完成〕切换，已完成的主线与支线任务统一收进「已完成」列表，不占背包格。
- **重新打开与已完成任务单子项恢复**：
  - 在「已完成」列表或已完成任务详情里点〔重新打开〕，会按完成批次快照把当时一并完成的子项恢复为「待做」（早先单独完成的子项保持完成；旧自动完成任务只把任务放回背包），不会自动开始计时。
  - 也可以点已完成任务的〔详情 ›〕，对其中某一个子任务单独点〔取消完成〕：任务会一并回到背包，且**只恢复所点的那一项为待做**，其余已完成子项保持完成。
  - 若对应的主线或支线背包格已满，会先让你明确选择要冷藏或放弃哪一个同槽位任务来腾位。

## 自由计时与小窗口：显式〔插入事件〕

- **自由计时卡头〔＋ 插入事件〕**：主窗口在自由计时运行中或已暂停时，融合布局与分开布局的自由记录卡右上角都提供〔＋ 插入事件〕，点击后插入卡立刻落下，直接输入事件名称并选项目，按回车开始、按 Esc 或〔回到任务〕撤回。普通输入框、收藏、最近记录仍保持自由计时原本的切换行为。
- **小窗口与超小窗口 `+` 插入按钮**：520×88 小窗口与 320×46 超小窗口在任务计时或自由计时（运行中或已暂停）时提供紧凑的 `+`〔插入事件〕按钮，就地输入名称并可选分类，回车开始、Esc 撤回，与主窗口共享同一套草稿协调与防冲突保护。

## 从背包开始任务：拉开大幕转场与底栏紧凑排布

- **背包开始任务大幕转场（Wipe）**：无论从抽卡翻面后的〔开始〕、今日任务板行上的〔开始〕，还是任务详情里的〔开始〕启动任务卡，都会在背包抽屉收起后播放 `START TASK / 开始计时` 拉开大幕转场，再进入首页任务卡与计数滚动；抽卡翻面预览保持不变，简化/关闭动效设置照常生效。
- **底栏左侧四按钮紧凑间距**：主窗口底栏左侧〔快捷活动〕、〔+ 快速记录〕、〔开启/关闭小窗口〕、〔背包〕四个按钮统一收进紧凑分组（6px 间距），视觉更集中。

## AI 与自动化（MCP / CLI 36 方法全覆盖）

- 在原有 17 个方法基础上新增 **19 个方法（14 写、5 读，合计 36 个方法）**，覆盖：
  - **今日任务板与抽卡**：`get_task_plan`（`plan show`）、`add_plan_item`（`plan add`）、`remove_plan_item`（`plan remove`）、`update_plan_item`（`plan edit`）、`confirm_plan_carry`（`plan carry`）、`skip_today_plan`（`plan skip-today`）、`draw_task_item`（`plan draw`，纯只读）、`skip_task_item`（`plan skip`）。
  - **做卡闭环与插入结算**：`complete_task_item`（`item done`）、`reopen_task_item`（`item reopen`）、`keep_going_task_item`（`item keep`）、`split_task_item`（`item split`）、`end_original_task`（`break end-original`）。
  - **整张任务与想法池恢复**：`get_task_details`（`task show`）、`complete_task`（`task done`）、`reopen_task`（`task reopen`）、`reopen_idea`（`idea reopen`）。
  - **复盘汇总与操作历史只读查询**：`get_recap`（`recap show`）、`list_operation_history`（`history list`）。
- 所有写方法均纳入 `operation_id` 幂等回执与操作历史（`auto.<method>`）。
