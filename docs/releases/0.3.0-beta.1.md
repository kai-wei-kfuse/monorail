# 单轨 0.3.0-beta.1

这是 Beta 测试版，可能存在尚未发现的问题，欢迎在实际使用中反馈。

- 新增统一应用接口层，随安装包内置本地 MCP 服务（`monorail-mcp.mjs`）与命令行工具（`monorail-cli.mjs`），支持保存想法、快速捕获待办、查询上下文与时间统计、控制计时与休息插入，以及操作回执幂等重放。
- 在「设置 → 关于 → 软件更新」新增「加入 Beta 体验 / 退出 Beta」与当前更新渠道显示：
  - 默认使用稳定版渠道；加入 Beta 为本地自愿切换，无需账号申请或提交个人信息。
  - 退出 Beta 后立即切回稳定版渠道，可选择留在当前版本等待后续正式版，或点击「安装稳定版」在核验数据兼容性后覆盖安装较低的兼容稳定版本（如 `v0.2.5`）。
- 应用内安装更新前新增冻结状态完整数据与配置备份（含业务记录、附件、操作回执及目录授权）与 SHA-256 校验；覆盖安装保留 Beta 期间新增的数据，不自动还原旧备份。
- 支持从 GitHub Releases 下载同产品安装包直接覆盖安装（向导中选择「请勿卸载」，不勾选「删除应用程序数据」），保留原有数据目录、设置与授权。

旧版没有 Beta 入口时，请先退出单轨，下载本页 Windows 安装包覆盖原安装，再到「设置 → 关于」选择是否加入 Beta。手动安装本包不会自动加入 Beta 渠道，覆盖安装前建议额外复制数据目录备份。

MCP 和 CLI 使用说明见仓库的 `docs/application/README.md` 与 `mcp/README.md`；运行它们需要本机安装 Node.js 24。
