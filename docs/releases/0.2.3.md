# 单轨 0.2.3

- 新增「小小窗口」模式，可在设置中切换为只显示名称、计时和按钮的单行窗口。
- 修复小窗口拖动时闪烁、出现多余黑底及高度被压矮的问题；只允许横向调整，限制宽度并避开任务栏，重新打开应用时保留调整后的宽度。
- 统一卡片标题、小窗标题和时间读数的透明就地编辑体验，保留字号、将光标放到末尾，支持回车提交和 Esc 取消。
- 小窗可直接点击时间修改读数；待机和待确认状态下，修改时间涉及已有记录时先显示覆盖确认。
- 主窗口底栏新增「快速记录」按钮；修复记录条拖动时意外隐藏，以及自动隐藏后快捷键无法再次打开的问题。
- 日历增加 1×–4× 比例和 Ctrl＋滚轮缩放，缩放时保持查看的中心时刻，切换页面后记住本次使用的比例；改善短记录块的名称和时间提示。
- 移除首页独立收藏栏，修复主窗口重新获得焦点时重复播放入场动画的问题。

不改变数据格式。旧设置默认使用普通小窗口。
