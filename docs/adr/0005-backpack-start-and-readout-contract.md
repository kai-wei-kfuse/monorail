# ADR 0005：背包直接启动与读数编辑契约

- 状态：Accepted
- 日期：2026-10-31
- 生效版本：0.2.4
- 依据：用户已要求背包直接启动、统一时长显示和精简界面，并在发版前确认已完成手测。

## 决定

背包增加指定事项的启动入口。单事项任务在标题下方提供「开始」，拆分后的每个事项分别提供「开始」，进行中的事项显示禁用的「进行中」。启动后停留在背包页；组装层复用 `homeService.startCard` 的完整事务，包括原有 `pending_at` 起点、切换计时、清理休息与卡状态对齐。抽卡继续作为另一种选择方式，不增加背包专用启动服务。

所有当前计时读数及列表时长采用 `formatReadout(ms, 'mmss')`：不到一小时显示 `MM:SS`，满一小时显示 `HH:MM:SS`，超过一天不回绕。对应编辑入口按两段分秒、三段时分秒解析。保留 `hms` 兼容契约：始终显示三段，双段输入仍按时分解析；全局 `parseDuration` 的其他表单规则不变。

任务菜单移至分类选择器右侧；列表分类与标签复用 flat 样式并缩短列宽；自由记录仅调整字号和内容宽度，保留 `useEntry`、项目与标签快捷解析及焦点组提交机制。TaskCard 进入就地编辑时保留已适配字号。

## 影响与验证

上述入口、展示与编辑规则取代旧产品图中的「首页唯一入口」及旧读数/布局示例；已同步仓库外的产品、架构与 UI 文档。当前范围集中在 `docs/stages/0.2.4.md`，回顾与计时解耦另见 ADR 0004。

不改变 schemaVersion 2，不修改迁移、原生命令、更新签名或安装协议。专项回归、全量检查、正式配置构建与用户手测确认见 `evidence/release-0.2.4/summary.md`。
