# ADR 0017：在设置中提供 MCP / CLI 使用说明

状态：Accepted（已实现于 0.3.0-beta.2）· 2026-11-04。

## 背景

用户此前要求设置内的 CLI/MCP 说明入口。beta.1 交付了工具和仓库文档，却没有应用内说明页；Beta 更新执行方案还明确排除了该栏目。用户本轮确认将这项遗漏列入 beta.2，在新 session 开发。

## 决定

1. 设置增加独立「AI 与自动化」说明页，包含能力说明、MCP 配置、CLI 示例、运行前提与排错；沿用现有设置页风格。
2. 当前分发的实际路径是配置展示依据；MCP JSON 和 PowerShell 命令可复制，不硬编码开发目录或假定全局命令已安装。路径读取失败明确显示，不猜测。
3. 页面只说明和帮助连接已有能力，不成为新的业务入口/状态所有者，不改变共享应用接口、权限体系或 Beta 更新机制。
4. 本决定对 beta.2 明确接受页面范围，取代 beta.1 计划中对本栏目的排除；beta.1 已发布内容与历史计划保持可追溯。

## 影响与验证

影响设置导航、说明展示及必要的只读运行时路径接线；具体文件由开发时核对，复用现有安装元信息。需求和验收以 [beta.2 当前计划](../stages/0.3.0-beta.2.md) 为准。必须在隔离安装版中实测复制配置连接 MCP 和 CLI，不以源码树路径或静态截图替代；测试前关闭 autostart，避免再次残留登录启动项。
