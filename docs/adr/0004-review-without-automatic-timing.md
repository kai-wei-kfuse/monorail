# ADR 0004：回顾流程不再自动控制计时

- 状态：Accepted
- 日期：2026-10-31
- 生效版本：0.2.4
- 依据：用户明确要求「把这个机制删除，打开回顾不计时」。

## 问题与决定

旧设计附录 A8 与架构 §2.1、§2.4 将进入回顾视为计时切换：释放进行中的卡、清空休息、开始「回顾」条目，完成后切回待机。仅查看页面也会打断用户正在记录的活动。

删除回顾服务对计时系统的直接调用。进入、重新进入和完成回顾只管理回顾进度，不开始、恢复或停止计时，不释放正在进行的卡，不清空休息、回到目标或待确认状态。回顾步骤、完成条件和每日底线规则保持原有语义。

主线复盘中明确冷藏或放弃任务，仍由背包服务按原规则结束该任务的计时；这是用户的任务操作，不是打开或完成回顾的副作用。

## 兼容性与取舍

保留 schemaVersion 2、历史计时条目、系统项目「回顾」及旧文件中的 `timer_entry_id`；该字段仅为历史兼容，不再用于控制计时。新回顾的该字段为空。升级后不自动停止旧版已经开启的回顾条目，用户可通过既有计时入口切换活动，避免升级悄悄修改正在记录的事实。

不增加开关、手动回顾计时按钮或数据迁移。不再保留仅凭旧引用在完成时停止计时的第二套生命周期。

## 验证

服务测试核对进入、重进和完成前后计时条目及关联状态不变，覆盖进行中的卡、快捷活动、暂停、休息、睡眠、待确认以及带历史计时引用的回顾。继续验证回顾进度恢复和完整完成流程。运行类型、lint、全量测试、版本一致性和构建检查；实际结果另记 `evidence/0.2.4-review-timing.md`。
