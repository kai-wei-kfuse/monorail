## Current Plan（v1.26）

沿用 [版本开发流程](../版本开发流程.md) 和 `../../CLAUDE.md`。本版进度集中维护在本文，实际检查与交接见 [开工与验证记录](../../evidence/0.2.5-preparation.md)，主审记录见 [0.2.5 审核记录](../../evidence/0.2.5-review.md)，临时活动抽屉开发方案见 [AwayDrawer 开发方案](../../evidence/0.2.5-away-drawer-plan.md)，快捷活动延迟优化方案见 [QuickActs 延迟诊断与优化方案](../../evidence/0.2.5-quickacts-latency-plan.md)。

用户已提出本版需求：

1. **默认融合模式**：`src/shared/settings.ts` 中 `homeLayout` 默认值由 `'split'` 改为 `'fused'`（仅缺失 `settings.yaml` 的新数据目录默认使用融合布局；已有 `settings.yaml` 与冻结的 v2 迁移逻辑保持原值兼容）。
2. **小小窗口改名为 mini窗口**：`src/pages/settings/sections.ts` 中 `08 窗口与数据 -> 小窗口样式`（`miniMode`）的 `tiny` 选项显示名称及说明文案由「小小窗口」改为「mini窗口」，持久化枚举值 `'tiny'` 不变。
3. **默认颜色改为薄荷绿**：`src/shared/settings.ts` 中 `accent` 默认值及 `src/ui/styles/tokens.css` 的 `:root --yellow` 初始值由信号黄 `#fffa00` 改为薄荷绿 `#00f5a0`（已有用户配置与冻结迁移不变）。
4. **设置-05-快捷活动（预设编辑器）分类和标签改为列表同款无框样式**：`src/pages/settings/PresetEditor.tsx`（由设置 `05 预设与休息池` 的「收藏」与「快捷活动」两组共用）中的 `ProjectPicker` 与 `TagPicker` 改为 `flat` 无框样式，并在 `src/pages/settings/settings.css` 中对齐 `.pe-row .combo.flat` 与 `.pe-row > .tagpick.flat` 宽度规则，去掉分类和标签外框。
5. **首页右上角临时活动下拉抽屉（`AwayDrawer`）与底层卡片保持不变（[ADR 0006](../adr/0006-home-away-drawer-and-underlying-card-preservation.md)）**：
   - 已按既有流程先在 HTML 原型（`C:\Users\kai_wei\Documents\1026(4)\原型\页面\`）完成 v1→v4 迭代并通过 `原型/测试/` 全部 7 项测试，原型截图已归档至 `C:\Users\kai_wei\Documents\1026(4)\UI参考截图\v0.2.5-01..05-*.png`，获用户明确确认。
   - 插入快捷活动/临时活动（`kind === '插入'`，如「上厕所」）时，底层首页卡片（任务卡、自由记录卡、空卡及分开布局计时条）内容保持原状不变，底层进行中活动的状态文字显示为单行 `进行中（暂停）`（`PAUSED`）。
   - 在首页 `.home-stage` 右上角弹出浅色简约风格的临时活动下拉抽屉（`AwayDrawer`），展示 `■ 临时活动 │ 记到 <ProjectPicker flat> <TagPicker flat> · 开始于 HH:MM`、可就地编辑的活动名称、`〔回来 ←〕` 按钮及可点改的 `ELAPSED 临时计时` 读数；采用双层同心切角背景层 `.away-bg` 实现 1px 等宽严丝合缝边线且不裁切下拉弹层，随容器 `cqi`/`cqh` 响应式缩放且不遮挡下方进度竖条与主计时读数；去除旧 `--cyan` 蓝色状态点，统一为 `var(--yellow)`。
6. **日历页说明行删除、底栏「主线/支线」删除与停止按钮红标放大**：
   - 删除日历页（`src/pages/calendar/CalendarPage.tsx`）头部下方的操作说明文字行（`.s-desc`），并在 `src/pages/calendar/calendar.css` 中将 `.pg.cal` 网格行改为 `grid-template-rows: auto minmax(0, 1fr)` 以保持日历看板占满剩余高度；
   - 删除主窗口及预览底栏（`src/app/MainApp.tsx` 等）右侧的「主线 · 支线 ·」底线标记（`BaselineMarks`）；
   - 将首页计时条与融合大卡中的方形停止按钮（`StopButton`，`.tbar-new.stop`）内部方块图标放大（`22×22`，内部方块 `M3 3h10v10H3z`）并改为红色（`color: var(--red)`，悬停时红底白字 `background: var(--red); color: #fff`）。
