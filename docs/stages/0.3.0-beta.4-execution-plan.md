## 2. 做法要点

### F1 / F3（D2）
- 存法、规则、兼容按 ADR 0020。`ideaService.complete(ctx, id, at, source?)`、`uncomplete(ctx, id, at)`；`completeIdeaInTx` 供接口复用。
- 投影：`BackpackSlice.ideas` 不变（活跃池 + 已转任务），新增 `doneIdeas`（`completedAt`、`completedBy`）。
- 界面按 `../原型/页面/idea-done-prototype.html`：分段、按钮、已完成列表、空列表文字、面板说明加一句；完成后用通知提示「已完成「…」，收进「已完成」；在那里可以撤销」。

### F2（D2 接口）
- `complete_idea` 输入 `{ operation_id, idea_id }`，结果 `{ id, text, status: '已完成', completed_at, noop }`；错误 `IDEA_NOT_FOUND` / `IDEA_NOT_ACTIVE`。
- 方法数 15 → 16，写方法 10 → 11：同步 MCP 工具表、CLI 命令表与帮助、`docs/application/README.md`、`mcp/README.md`、设置 09 能力列表与它的测试、MCP / CLI 冒烟里的方法清单。

### F4–F6（D1）
- 自动完成数据由新的纯函数 `services/suggestSource.ts` 生成，主窗口 `timerView` 与 `miniProjection` 共用（规则同 `pages/home/suggestions.ts`）。小窗快照的「最近的记录」先按描述去重、去掉待机 / 休息 / 睡眠，最多 100 条（每秒心跳都要发，避免一年数据全发；比主窗口少的只是 100 条以前的同名记录）。按快照对象缓存，心跳不重算。
- 小窗命令新增（都带 `revision`、`pending_id` 身份校验，与现有命令一致）：`startFavorite { presetId }`、`startCard { targetCardId }`、`continueEntry { targetEntryId }`，分别走主窗口同一套 InTx；历史动作 `mini.startFavorite / mini.startCard / mini.continueEntry`，来源「手动 · 小窗」。
- 规则照主窗口：只在写新事件时出现自动完成（待机点名称、待确认时）；改正在计的那条时不出现；选中即开始；只能鼠标点。写新事件时选的分类随 `editOpen.patch.project` 发出，名称里写了 `@项目` 以名称为准。
- mini 窗口：名称右边常驻分类块（色点 + 名字，最宽 72px，省略号；待机且不在写时不显示）；有分类块时左区右内边距 4px；去掉关闭「×」；读数 16px。计时中的是卡时改的是卡（沿用）。小窗里不新建分类。
- 弹层（自动完成、分类下拉）贴着小窗、与窗口同宽。窗口变高交给 Rust `fit_mini_window(width, barHeight, popupHeight)`：以收起时的小窗位置为锚点，下面放得下就往下；放不下且上面更宽就往上（窗口上移、小窗本体在屏幕上不动）；弹层高度不超过所选一侧的工作区剩余；返回方向与实际高度。收起时 `fit_mini_window(width, barHeight, 0)` 复位。展开期间 `save_geometry` 不保存、不夹紧；展开时用户拖动小窗，按方向换算回锚点再保存。
