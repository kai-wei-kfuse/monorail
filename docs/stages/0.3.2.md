   - 这是**新增子项完成入口**，不是取消第 1 条整张完成，也不是把已交的整套 GUI 标成已确认。
   - 两条路都要有：可以选择完成**单个子项**，也可以**直接完成整个任务**（主线 / 支线）。
   - 看的是第 1 条任务详情 / 完成原型；不是第 3–6 条。

   **用户随后确认（2026-11-07，经 coder-3 转达，不是一条长原话）**：
   - **入口位置**：任务详情的**每一行**子任务（如点行左侧方框 / 按钮完成该子项）；底部〔✓ 完成〕完成整个任务；今日任务板不加。
   - **取消完成**：支持在任务详情里点已完成的子任务取消完成，恢复回待做。这是子项级恢复，不是第 1 条整张任务从已完成列表重新打开。

   **本条没有说、因此不改的**：第 1 条已确认的整张完成时剩余项一并完成、完成后腾格 / 已完成列表 / 可撤销整张任务。今日任务板的行仍不加整张〔完成〕。

   **方案（ADR 0022 Accepted 修订4 / 执行方案 v1.7）**：每行左方框按钮与右〔完成〕/〔取消完成〕同一动作；待做子项直接完成、不强制先计时；主线逐项完成后仍留背包；支线尾项自动完成；已完成列表可进详情、只恢复单项（不先整批 reopen）；取消完成恢复待做。S1–S5 / N1–N5 已吸收。两审通过。coder-3 已开始实现。恢复弹窗文案建议已吸收。不能写成 GUI 已确认或实现已完成，不含发版授权。

   已纳入本版范围。未改代码。
