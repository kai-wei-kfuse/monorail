# 0.2.4 开发计划

版本：v1.11 · 2026-10-31 · 已公开发布，签名与更新清单核验通过

## Current Plan（v1.11）

本版从删除打开回顾自动计时开始，已获用户明确授权。该项属于回顾与计时之间的结构调整，决定见 [ADR 0004](../adr/0004-review-without-automatic-timing.md)。旧 0.2.0 计划 §4.2 中「重进回顾新建计时」及 §5 中「进入回顾改变计时并对齐」是历史规则，本版由 ADR 0004 及同步后的设计文档替代。

在此基础上，按用户要求增加「背包任务池直接点击开始计时」、任务卡交互优化、计时读数进位显示、列表页简约分类/标签样式与单行防折行，以及融合布局自由记录与任务卡标题样式统一：

入口与读数契约依据 [ADR 0005](../adr/0005-backpack-start-and-readout-contract.md)。用户于 2026-10-31 确认「我已经测试过了」，随后明确授权发版。已从审核提交 `f6bcc0a` 发布 [v0.2.4](https://github.com/kai-wei-kfuse/monorail/releases/tag/v0.2.4)；完整证据见 [审核与发布记录](../../evidence/release-0.2.4/summary.md)。

1. 单事项任务在标题下方 Meta 行右侧加开始按钮，多事项任务在每个小任务行右侧加开始按钮；正在计时时按钮文案替换为「进行中」并禁用；由组装层 `BackpackScreen` 直接调用 `homeService.startCard`，不自动跳回首页。
2. 将「拆开」改为「拆分任务」，「＋ 加一项」改为「添加任务」，并与「冷藏」「放弃」一起收进双向下箭头（`Tri2`）下拉菜单；下拉菜单按钮移至「分类（`ProjectPicker`）」右侧同一行（`.qc-proj`），去掉左侧的「计时记到」文字（保留 `LOG TO`），并修正双向下箭头按钮内图标的正中心对齐。
3. 修复任务卡牌右下角折角斜线因 `border-box` 与 `padding-box` 坐标偏差导致的边线不对齐问题，同时避免 `clip-path` 裁切下拉弹层。
4. 计时读数格式统一按小时、分钟、秒进位显示，不再累加显示为几百分钟：不到 1 小时显示 `MM:SS`（不显示 `00:` 前缀），满 1 小时起进位显示 `HH:MM:SS`（覆盖 `formatReadout`、`formatMinutes`、首页卡片与计时条、小窗、背包卡片已用时长及列表页时长 `duration` 与编辑解析）。
5. 列表页（`EntryRow`）分类选择与标签选择改为与首页卡片头部一致的无边框简约样式（`ProjectPicker flat` + `TagPicker flat`，合并行标签芯片同步无框化），并缩短中间各列（描述、分类、标签、起止、时长）的基础与最小宽度、设置 `.lv-row` 单行不折行（`flex-wrap: nowrap`），防止右侧 `⋯` 按钮掉到下一行。
6. 融合布局（`FusedCard`）下，保持 `.f-input` 与 `useEntry` 的输入/提交架构不变（完整保留 `#标签` 与项目快捷语法解析及焦点组联动），将 `.f-title` 字号统一为 `--ts`（按 `titleScale` 计算，默认 65% 下 `62px`），并在已有文字且未展开建议框时启用 `.f-input.compact`（`field-sizing: content`），使 L 形角标紧凑包裹文字宽度，与任务卡视觉完全统一。
