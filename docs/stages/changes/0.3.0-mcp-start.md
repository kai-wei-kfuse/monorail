## Stage Change Proposal

### Problem
用户已授权开发 MCP Server，首个能力为保存想法。0.2.5 已发布，无外部调用入口。

### Why It Matters
独立进程直接写文件会绕过主窗口提交队列和更新/迁移协调。

### Options
直接写文件；增加网络服务；使用本机管道转交现有应用服务。

### Decision
新开 0.3.0 阶段，仅交付保存想法。采用官方 TypeScript SDK 的 stdio Server，通过 Windows 命名管道调用运行中的桌面应用；ADR 0008 记录边界。不回写 0.2.5 已发布范围。

### Impact
新增 Node MCP 入口、原生管道和主窗口适配；复用 recordService 与现有模型，不迁移数据、不新增 UI。
