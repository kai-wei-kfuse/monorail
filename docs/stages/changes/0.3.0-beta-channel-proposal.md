# Stage Change Proposal：0.3.0 Beta 加入、退出与稳定版覆盖

状态：Accepted · 2026-11-03。用户明确授权制定执行方案并交 coder-3 实施；该请求授权扩展本版更新范围，不包含实际发布或安装用户日常版本。

### Problem

0.3.0 的统一接口/MCP/CLI 与 M9 已完成，但用户需要真实使用 Beta，并在「检查更新」处加入/退出。现有更新器固定 GitHub latest 正式 Release，默认只接受更高版本；发布脚本把 `--prerelease` 专用于 update-test 验收标签，尚不支持产品 Beta 渠道。

### Why It Matters

仅勾 GitHub Pre-release 不会让现有应用收到 Beta。退出渠道也不等同于把较高 Beta 安装替换为较低稳定版；应用选择、SDK 比较、NSIS 覆盖和数据兼容必须同时成立。旧稳定版无法回溯增加新入口，因此必须支持从 GitHub 下载新安装包覆盖现有产品且不覆盖业务数据。

### Options

1. 独立 Beta 产品/数据目录：适合并行测试，但不满足用户本次在原安装中加入和退回的目标。
2. 同产品双渠道、仅等待更高稳定版：实现较小，但不满足用户选择稳定版覆盖安装的要求。
3. 同产品双渠道，显式选定兼容稳定版时允许覆盖回退；沿用签名更新与原保存封口。采用。

### Decision

增加加入/退出 Beta 及显式稳定版返回。保持产品名、identifier、当前用户安装身份和数据路径；渠道偏好独立持久化在应用配置目录，更新快照仍由原生状态机唯一拥有。Beta 0.3 系列保持与已核验稳定版的数据格式兼容；不通过自动恢复旧备份实现回退，不允许丢掉 Beta 期间的新数据。详见 ADR 0016 与执行方案。

### Impact

涉及更新 UI/IPC/原生状态、Release 选择/比较、安装前备份、版本兼容声明、发布脚本/CI、隔离安装升降级验收。原 M0–M9 已完成证据保留；新增 B0–B5 独立勾选。手机、远程、AI与自动化设置栏以及公开匿名更新认证不纳入本轮。
